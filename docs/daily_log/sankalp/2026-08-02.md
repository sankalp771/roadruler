## [16:02:00] Task: Day 5 - ResNet50 Visual Embedding Vector Generator

### 1. Objective & Architectural Rationale
- Implement the ResNet50 visual feature extractor module to extract high-dimensional deep feature vectors (embeddings) from road damage photos.
- Visual embeddings represent semantic representations of images, serving as visual fingerprints. In Phase 2 (Day 8), these embeddings will be compared using Cosine Similarity to identify duplicate complaints and prevent redundant database records.
- Standard ImageNet pre-processing and L2-normalization must be applied to ensure that the vectors reside on a unit sphere (norm = 1.0) of shape (2048,), which is required for reliable cosine similarity measurements.

### 3. Implementation Details
- Designed `ResNet50FeatureExtractor` class loading pre-trained weights from `torchvision.models.resnet50`.
- Stripped the final fully connected classification layer (`resnet.fc`) by replacing it with `nn.Identity()` to extract the raw 2048-dimensional feature vectors.
- Configured the extractor in `eval()` mode.
- Implemented `extract_embedding(image_input)` supporting raw image bytes, PIL Images, OpenCV BGR arrays, and image file paths.
- Applied resizing to 224x224 and ImageNet standard normalization `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`.
- Performed inference on CPU inside a `torch.no_grad()` block to eliminate gradient computations.
- Flattened the extracted feature map and L2-normalized the vector.
