### 3. Implementation Details
- Implemented `RoadDamageDetector` class with configurable `weights_path` and `conf_threshold`.
- Built robust input preprocessing method `_preprocess_input` converting file path, raw bytes (`io.BytesIO`), `PIL.Image`, or `np.ndarray` into OpenCV BGR format.
- Mapped class IDs to standard RDD2022 road damage categories (`Pothole`, `Longitudinal Crack`, `Transverse Crack`, `Alligator Crack`, `Waterlogging`) with fallback to model's default class names.
- Calculated normalized bounding box coordinates $(x_1, y_1, x_2, y_2)$ relative to image dimensions for down-stream spatial alignment.
- Added CLI interface via `argparse` for modular testing and execution.
